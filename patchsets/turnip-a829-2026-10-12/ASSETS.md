# Release assets

- `punktfunk-turnip-decode-feedback.apk`: final installed client.
- `turnip-a829-mesa-745709a.zip`: app-importable driver.
- `turnip-client-native-libraries.zip`: six exact libraries plus AdrenoTools source snapshot and native license notices.
- `turnip-final-validation-evidence.zip`: final sustained/cooling/recovery traces and helpers.
- `turnip-complete-session-archive.zip`: all 74 artifacts from the earlier session, including superseded test APKs, gameplay capture, screenshots, patches and reports. Earlier APKs are historical experiments; use the final APK for normal streaming.
- `turnip-diagnostic-source.zip`: replay harness changes and measurement helpers.
- `SHA256SUMS`: asset checksums.

No Android signing private key, pairing database or account credential is included. Installation from an independently built APK requires a matching signing key to retain the existing app identity.
